datasette-leaflet 0.3
ENRelease: datasette-leaflet 0.3 OpenStreetMap have a very reasonable policy that hits to their hosted tile server should send a referrer header. Datasette table pages used the Referrer-Policy: no-referrer HTTP header, causing plugins that loaded tiles from OpenStreetMap to violate that policy. datasette-leaflet is the plugin that loads a bundled Leaflet so other Datasette plugins can depend on it. It now sets the referrer policy on the tile requests themselves to strict-origin-when-cross-origin, passing the host but not the full path to the page. Tags: leaflet, datasette, openstreetmap
中文datasette-leaflet 0.3 为 OpenStreetMap 瓦片请求设置来源策略，发送站点来源而不暴露完整页面路径。
https://simonwillison.net/2026/Nov/13/datasette-leaflet/
